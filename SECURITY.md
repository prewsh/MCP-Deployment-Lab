# Security policy

MCP Deployment Lab is evolving experimental infrastructure software. Use sandbox credentials and sandbox targets only; production credentials and production infrastructure should not currently be entrusted to it.

Report a vulnerability privately to the repository maintainer rather than opening a public issue. Include a minimal reproduction, impact, and affected revision. Do not include credentials, bearer tokens, authorization headers, cookies, private keys, or environment-file contents in a report.

The project fails closed for missing execution-policy context, but operators remain responsible for restricting tokens, network exposure, and target scope.
